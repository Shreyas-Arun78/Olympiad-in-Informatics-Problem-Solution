# Olympiad-in-Informatics-Problem-Solution
This repository is created for personal learning, educational, and training purposes as part of my journey towards achieving a Gold Medal at the International Olympiad in Informatics (IOI). It contains my solutions, detailed editorials, explanations, observations, and problem-solving approaches for a wide variety of Olympiad in Informatics (OI) & Competitive Programming (CP) problems. The goal is to maintain a comprehensive collection of my learning, document the ideas and techniques I discover, and provide a useful resource for future revision and for other students preparing for OI competitions.

# I am solving (or have solved) problems from :

CSES Problem Set - https://cses.fi/problemset/ (best to make your foundation strong)

AtCoder Educational DP contest - https://atcoder.jp/contests/dp/tasks (best to strong your Dynamic Programming)

Codeforces Problem Set - https://codeforces.com/problemset (best for speed solving and fast implementation)
